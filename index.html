How to use them

Take them in order. S1 is quiz level, S2 adds multi-step calculations, and S3 asks you to work backwards. No question repeats across the three.

Print or work on a tablet. Each exam ends with a bubble answer sheet and a formula page. Leave the formula page closed if your real exam does not give you one.

Grade with the key, then read it. Every key opens with the answer grid and a topic table, then explains each answer and why the tempting wrong choices fail.

Use your misses. The topic table in each key shows which skill a missed question tests, so you know what to review in the lesson.
